# RouletteBridge v0.1.8

관리자 페이지의 브리지 설정 접기 동작을 실제 UI 표시까지 정상화한 패치 릴리스입니다.

## 주요 변경 사항

- SOOP 연결 완료 후 `브리지 설정` 패널이 실제로 접히도록 수정
- 기존에는 버튼 문구와 상태만 바뀌고 `.config-form { display: grid; }` 때문에 본문이 계속 보이던 문제 해결
- `data-collapsed=true` 상태에서 설정 폼을 `display: none !important`로 숨기도록 보강
- 접힌 상태에서는 설정 설명 문구와 불필요한 여백도 숨겨 `브리지 설정` 제목과 `설정 펼치기` 버튼만 표시
- 관리자 CSS 캐시 버전을 갱신해 기존 스타일이 브라우저 캐시에 남아 수정이 반영되지 않는 문제 방지

## 포함된 안정화 기능

- SOOP 수동 강제 재연결 및 반복 재연결 안정화
- 재연결 시도별 timeout 분리
- 트레이 종료 시 graceful shutdown 및 프로세스 잔류 방지
- 관리자 페이지에서 config.json 편집 및 자동 재실행
- 최초 설정 필요 시 관리자 페이지 자동 열기
- 관리자 페이지 및 OBS 오버레이 자동 재연결
- OBS 오버레이 주소 확인 및 복사
- 수동 누적 보정 사용자 자동 확인 및 신규 사용자 SOOP 직접 조회

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.8.zip`을 다운로드해 압축을 해제합니다.
2. 기존 운영 데이터를 유지하려면 `config.json`, `data/`, `tickets/`, `backups/`를 보존합니다.
3. `RouletteBridge.exe`를 실행합니다.
4. SOOP 연결이 완료되면 관리자 페이지의 브리지 설정 영역이 자동으로 접히는지 확인합니다.
