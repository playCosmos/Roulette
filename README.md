# 먀로또 추첨기

`assets/Frame.png`를 그대로 사용하는 정적 웹 추첨기입니다. 이미지의 입 위치에 슬롯머신형 이빨 릴을 겹쳐 렌더링하며, 이미지 클릭 또는 `Space` 키로 회전/정지를 제어합니다.

## 현재 동작

- 이빨은 앞뒤로 뒤집히지 않고 세로 방향 슬롯 릴처럼 연속 스크롤
- 이미지 클릭 또는 `Space` 키: 회전 시작 / 정지 시작
- 왼쪽 릴부터 오른쪽 릴까지 순차 감속/정지
- 마지막 릴은 추가 지연 후 정지
- 번호 범위 설정 가능
- 뽑는 개수 `1~7` 설정 가능
- 중복은 항상 비허용
- 번호 범위와 뽑는 개수는 `localStorage`에 저장되어 다음 방문에도 유지
- Web Crypto API 기반 추첨
- 추첨 완료 시 최근 200회 자동 기록
- 현재 결과 / 개별 기록 / 전체 기록 복사 시 번호만 복사
- 날짜와 시간은 저장·표시·복사하지 않음
- 페이지 자체는 뷰포트 안에 맞춰져 문서 스크롤이 발생하지 않도록 구성
- 이미지 크기가 변하면 입 위 이빨 릴도 같은 비율로 함께 스케일
- GitHub Pages에서 빌드 없이 실행

## 이미지

Base64나 별도 이미지 로더를 사용하지 않습니다.

```text
assets/Frame.png
```

`index.html`에서 일반 PNG 파일로 직접 참조합니다.

## 구조

```text
.
├─ index.html
├─ styles.css
├─ app.js
├─ .nojekyll
└─ assets/
   └─ Frame.png
```

## 실행

별도 빌드 과정이 없습니다.

```bash
python -m http.server 8080
```

또는 GitHub Pages에서 `main` / `/ (root)`를 배포 대상으로 지정하면 바로 실행할 수 있습니다.
