# RouletteBridge v0.1.6

Windows용 SOOP 자동 티켓 발급 브리지 배포판입니다.

## 주요 변경 사항

- 관리자 페이지에서 `config.json` 주요 설정을 직접 조회·수정·저장
- 최초 실행 시 스트리머 ID가 비어 있으면 관리자 페이지 자동 열기
- 스트리머/SOOP 연결 설정은 저장 즉시 적용
- 티켓 규칙, 서버 포트, 저장 경로 변경 시 브리지 자동 재시작
- `restart-bridge.ps1`을 배포본에 포함하여 사용자가 EXE를 다시 실행할 필요 없이 설정 적용
- 관리자 페이지가 브리지 종료/재시작 중 `브리지 연결 대기` 상태로 계속 폴링
- 브리지 복귀 시 관리자 페이지에 `다시 연결됨` 표시
- HTTP 포트가 변경되는 자동 재시작에서는 새 포트의 `/health` 확인 후 새 관리자 URL로 자동 이동
- OBS 오버레이 주소를 관리자 페이지에서 확인하고 복사 가능
- 열려 있는 방송용 오버레이가 브리지 재시작 시 WebSocket을 자동 재연결
- 오버레이 화면에는 연결 끊김/재연결 상태 문구를 표시하지 않음
- 자동 재시작으로 WebSocket/API 주소가 변경되면 오버레이가 새 주소를 사용
- 티켓 완료 ACK와 PNG 업로드 재시도 강화
- 수동 누적 보정에서 SOOP 사용자 ID 또는 닉네임 중 하나만 입력해도 상대 값을 자동 확인
- 기존 후원자는 SQLite donor 기록에서 먼저 확인
- 신규 값은 별도 SOOP 직접 조회 경로에서 확인
- 신규 직접 조회는 정확 일치만 자동 확정하고, 복수 후보/유사 결과는 임의 선택하지 않음
- 채팅 연결 시 `JOIN_CHANNEL` 30초 제한을 적용하여 `채팅 연결 중` 상태의 무한 대기 방지

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.6.zip`을 다운로드해 원하는 폴더에 압축을 해제합니다.
2. `RouletteBridge.exe`를 실행합니다.
3. 최초 설정이 필요한 경우 관리자 페이지가 자동으로 열립니다.
4. 관리자 페이지의 `브리지 설정`에서 스트리머 ID와 필요한 설정을 저장합니다.
5. 재시작이 필요한 설정은 프로그램이 자동으로 재실행하여 적용합니다.
6. 관리자 페이지의 `OBS 오버레이 주소`에서 URL을 복사하여 OBS Browser Source에 입력합니다.

기본 관리자 페이지:

```text
http://127.0.0.1:17820/soop-admin.html
```

기본 OBS Browser Source:

```text
http://127.0.0.1:17820/soop-overlay.html?ws=ws://127.0.0.1:17821
```

## 업데이트 시 주의

기존 운영 중이라면 다음 항목은 삭제하거나 새 배포본으로 덮어쓰지 마세요.

```text
config.json
data/
tickets/
backups/
```

SQLite `data/roulette.db`가 누적 및 발급 기록의 원본입니다.

## 검증

Windows CI에서 다음 항목을 통과한 배포본만 릴리스합니다.

- Admin/Overlay JavaScript 문법 검사
- Java 25 Maven build
- Phase D 후원 누적/자동 티켓 할당
- 중복 이벤트 차단
- Phase E PNG 저장 및 `ISSUED` 전환
- 동일 PNG 재업로드 멱등성
- Phase F 재시작 복구
- 기존 ticketId/번호 유지
- `FAILED` 자동복구 제외
- jpackage Windows GUI/Tray EXE 생성
- 내장 Java runtime 확인
- 배포 config의 빈 스트리머 설정 확인
- `restart-bridge.ps1` 포함 확인
- 관리자 및 오버레이 재연결 자산 포함 확인
- 배포본에 로그 폴더가 사전 생성되지 않는지 확인
- 패키지 EXE 자체 Phase F/encoding self-test
