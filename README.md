# 먀로또

`assets/Frame.png`를 그대로 사용하는 정적 웹 추첨기입니다. PNG 프레임 뒤쪽의 입 위치에 사각형 슬롯머신형 이빨 릴을 렌더링하며, GitHub Pages에서 별도 빌드 없이 실행됩니다.

## 화면 구성

오른쪽 컨트롤 영역은 탭 방식입니다.

- `추첨기`: 번호 범위와 뽑는 개수를 지정해 자동 추첨
- `번호 확인`: 저장된 추첨 기록 또는 복사해서 붙여넣은 여러 추첨 기록을 실제 당첨 번호와 비교

## 추첨기

- 이미지 클릭 또는 `Space` 키: 회전 시작 / 정지 시작
- 이빨 릴은 flip이 아니라 세로 슬롯머신 reel 방식으로 연속 스크롤
- 왼쪽 릴부터 오른쪽 릴까지 순차 감속/정지
- 마지막 릴은 추가 지연 후 정지
- 번호 범위 설정 가능
- 뽑는 개수 `1~7` 설정 가능
- 중복은 항상 비허용
- 번호 범위와 뽑는 개수는 `localStorage`에 저장
- Web Crypto API 기반 추첨
- 추첨 완료 시 최근 200회 자동 기록
- 현재 결과 / 개별 기록 / 전체 기록 복사 시 번호만 복사
- `전체 복사`는 한 줄에 한 조합씩 복사되어 번호 확인 탭에 그대로 붙여넣을 수 있음
- 날짜와 시간은 저장·표시·복사하지 않음

## 번호 확인

- 실제 당첨 번호를 공백 또는 쉼표로 입력
- 기존 자동 추첨 기록 전체와 일괄 비교
- `전체 복사`한 추첨 기록을 텍스트 영역에 그대로 붙여넣어 일괄 비교 가능
- 붙여넣기 형식은 한 줄에 한 조합, 각 번호는 공백·쉼표·세미콜론으로 구분 가능
- `현재 기록 넣기` 버튼으로 브라우저에 저장된 추첨 기록을 검사 입력창에 바로 불러올 수 있음
- 일치 번호를 결과 목록에서 강조 표시

### 보너스 번호 모드

`보너스 번호 사용` 체크박스로 판정 방식을 선택합니다. 이 설정도 `localStorage`에 유지됩니다.

- 체크 해제(기본): 보너스 번호 입력을 비활성화하고, 등수를 임의로 부여하지 않으며 각 기록을 `N개 일치` 형태로 표시
- 체크: 보너스 번호 입력을 활성화하며 보너스 번호 입력을 필수로 요구
- 체크 상태에서 당첨 번호 6개와 6개짜리 기록을 비교하면 로또 방식으로 판정
  - 6개 일치: 1등
  - 5개 + 보너스: 2등
  - 5개: 3등
  - 4개: 4등
  - 3개: 5등
  - 그 외: 낙첨
- 보너스 모드를 켠 상태에서 보너스 번호가 비어 있으면 검사를 실행하지 않음
- 6개 기록이 아닌 경우에는 기존처럼 `N개 일치` 형태로 표시
- 최근 입력한 당첨 번호와 보너스 번호도 `localStorage`에 유지

이렇게 해서 보너스 번호가 없는 상태에서 5개 일치를 자동으로 3등으로 판정하는 모호한 동작을 제거합니다.

## 이미지와 레이어

Base64나 별도 이미지 로더를 사용하지 않습니다.

```text
assets/Frame.png
```

릴 Canvas는 `Frame.png`보다 낮은 `z-index`에 배치되어 PNG의 입 구멍을 통해서만 보입니다. 페이지와 이미지가 축소·확대되어도 입 위치와 릴 크기는 비율로 함께 조정됩니다.

## 실행

별도 빌드 과정이 없습니다.

```bash
python -m http.server 8080
```

또는 GitHub Pages에서 `main` / `/ (root)`를 배포 대상으로 지정하면 바로 실행할 수 있습니다.
