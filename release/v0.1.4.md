# RouletteBridge v0.1.4

Windows용 SOOP 자동 티켓 발급 브리지 배포판입니다.

## 주요 기능

- SOOP 스트리머 ID 기준 현재 방송 자동 조회
- 채팅 서버 연결 및 후원 이벤트 처리 기반
- 후원자별 별풍선 누적
- 기본값 `50개 = 티켓 1장`
- 티켓마다 `1~28` 중 중복 없는 7개 번호 자동 확정
- 번호 확정 후 OBS 방송용 룰렛 연출
- 룰렛 완료 후 티켓 PNG 자동 저장
- 후원자별 발급 번호 및 이미지 기록 유지
- SQLite 기반 누적/후원/티켓 영구 저장
- 프로그램 및 OBS 재시작 시 미완료 티켓 복구
- DB 백업, 수동 누적 보정, manifest 재생성 지원
- Java 설치 없이 실행 가능한 Windows x64 self-contained 패키지
- Windows EXE 콘솔 및 로그의 한글 출력 지원

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.4.zip`을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. `config.json`의 `streamerId`에 실제 방송 대상 ID를 입력합니다.
4. `RouletteBridge.exe`를 실행합니다.
5. OBS Browser Source에 아래 주소를 사용합니다.

```text
http://127.0.0.1:17820/soop-overlay.html?ws=ws://127.0.0.1:17821
```

## 업데이트 시 주의

기존 운영 중이라면 아래 항목은 삭제하거나 덮어쓰지 마세요.

```text
config.json
data/
tickets/
backups/
logs/
```

SQLite `data/roulette.db`가 누적 및 발급 기록의 원본입니다.

## 검증

Windows CI에서 다음 항목을 통과한 배포본만 릴리스합니다.

- Maven build
- Phase D 후원 누적/자동 티켓 할당
- 중복 이벤트 차단
- Phase E PNG 저장 및 `ISSUED` 전환
- 동일 PNG 재업로드 멱등성
- Phase F 재시작 복구
- 기존 ticketId/번호 유지
- FAILED 자동복구 제외
- jpackage Windows EXE 생성
- 내장 Java runtime 확인
- 패키지 EXE 자체 Phase F self-test
- 패키지 EXE 한글 인코딩 probe
- 배포용 `config.json` 구조 검증
