# RouletteBridge v0.1.11

관리자 페이지의 후원자 누적 패널에서 현재 티켓 저장 폴더를 바로 열 수 있도록 개선한 릴리스입니다.

## 주요 변경 사항

- 관리자 페이지 `후원자 누적` 섹션에 `티켓 폴더 열기` 버튼 추가
- 버튼 클릭 시 현재 브리지가 실제로 사용하는 `ticketRoot`를 Windows 탐색기로 엽니다.
- 티켓 폴더가 아직 존재하지 않으면 생성한 뒤 엽니다.
- 브라우저가 임의 로컬 경로를 전달하지 않고 브리지가 관리 중인 실제 티켓 저장 경로만 열도록 제한했습니다.
- 폴더 열기 API는 loopback 요청만 허용합니다.
- Windows가 아닌 환경에서는 지원하지 않는다는 오류를 반환합니다.

## 포함된 기존 수정 사항

- 브리지 설정 저장 후 실제 저장은 성공했지만 `저장 실패`로 표시될 수 있던 재시작 타이밍 문제 수정
- SOOP 수동 강제 재연결 및 반복 재연결 안정화
- 트레이 종료 graceful shutdown 및 프로세스 잔류 방지
- 연결 완료 후 브리지 설정 패널 실제 collapse 처리
- 관리자 페이지/OBS 오버레이 자동 재연결
- 현재 채널 실시간 분석 페이지
- 채팅, 별풍선, 입장/퇴장, 구독, 팬레터, 미션, 관리/제재, reconnect/disconnect, RAW/unknown 등 전체 `ChatEvent` 관찰

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.11.zip`을 다운로드해 압축을 해제합니다.
2. 기존 운영 데이터를 유지하려면 기존 `config.json`, `data/`, `tickets/`, `backups/`를 보존합니다.
3. `RouletteBridge.exe`를 실행합니다.
4. 관리자 페이지의 `후원자 누적` 패널에서 `티켓 폴더 열기`를 누르면 현재 티켓 저장 폴더가 Windows 탐색기로 열립니다.
