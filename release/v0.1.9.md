# RouletteBridge v0.1.9

SOOP 현재 채널에서 수신되는 이벤트를 실시간으로 확인할 수 있는 채널 분석 페이지를 추가한 릴리스입니다.

## 주요 변경 사항

- 관리자 페이지에 `현재 채널 분석` 진입 버튼 추가
- `soop-channel.html` 실시간 이벤트 분석 페이지 추가
- 현재 `soopapi`가 발생시키는 전체 `ChatEvent`를 관찰용 listener로 수집
- 채팅, 입장/퇴장, JOIN, 별풍선, 팬레터, 구독, 미션, 아이템, 관리/제재, reconnect/disconnect, RAW/unknown 이벤트 확인 가능
- 이벤트별 시간, 이름, 코드, 요약 표시
- 이벤트 행을 펼쳐 parsed payload와 raw packet 확인 가능
- 이벤트 종류 필터, 검색, 일시정지/재개, 자동 스크롤, 화면 지우기 제공
- 이벤트 종류별 누적 카운트 표시
- 분석 API는 loopback-only로 제한
- 최근 이벤트는 운영 DB에 누적 저장하지 않고 메모리에 최대 5,000건 순환 보관
- 브리지 재시작 후 분석 페이지가 새 instanceId를 감지해 새 이벤트 스트림으로 전환

## 포함된 기존 안정화 사항

- SOOP 수동 강제 재연결 및 반복 재연결 안정화
- 재연결 시도별 timeout 분리
- 트레이 종료 시 graceful shutdown 및 프로세스 잔류 방지
- 관리자 페이지에서 config.json 편집 및 자동 재실행
- 최초 설정 필요 시 관리자 페이지 자동 열기
- 관리자 페이지 및 OBS 오버레이 자동 재연결
- OBS 오버레이 주소 확인 및 복사
- 수동 누적 보정 사용자 자동 확인 및 신규 사용자 SOOP 직접 조회
- 연결 완료 후 브리지 설정 패널 실제 collapse 처리

## 채널 분석 페이지

기본 주소:

```text
http://127.0.0.1:17820/soop-channel.html
```

관리자 페이지의 `현재 채널 분석` 버튼에서도 열 수 있습니다.

채널 이벤트 조회 API:

```text
GET /api/channel/events?after=<sequence>&limit=<count>
```

이 API는 로컬 loopback 요청만 허용합니다.

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.9.zip`을 다운로드해 압축을 해제합니다.
2. 기존 운영 데이터를 유지하려면 기존 `config.json`, `data/`, `tickets/`, `backups/`를 보존합니다.
3. `RouletteBridge.exe`를 실행합니다.
4. 관리자 페이지에서 SOOP 연결 상태를 확인합니다.
5. `현재 채널 분석`을 열어 실제 채팅/후원/채널 이벤트를 확인합니다.

## 검증

Windows CI에서 다음 항목을 다시 검증한 패키지만 게시합니다.

- Admin / Channel Analyzer / Overlay JavaScript 문법 검사
- Java 25 Maven build
- Phase D/E/F self-test
- Windows GUI/Tray app-image 생성
- 패키지된 EXE Phase F/encoding probe
- 내장 Java runtime 확인
- `restart-bridge.ps1` 포함 확인
- 관리자/오버레이/채널 분석 HTML/CSS/JS 자산 포함 확인
- 배포용 `streamerId` 공란 확인
- 배포본에 로그 폴더가 사전 생성되지 않는지 확인

## 확인이 필요한 운영 항목

모든 SOOP 이벤트 종류를 코드상 수집하도록 연결했지만, 팬레터·구독·미션·관리 이벤트 등 실제 방송에서 발생해야 하는 이벤트 각각의 payload는 실제 발생 시 채널 분석 페이지에서 확인해야 합니다.
