# 먀로또

`assets/Frame.png`를 그대로 사용하는 정적 웹 추첨기입니다. PNG 프레임 뒤쪽의 입 위치에 사각형 슬롯머신형 이빨 릴을 렌더링하며, GitHub Pages에서 별도 빌드 없이 실행됩니다.

## 화면 구성

오른쪽 컨트롤 영역은 탭 방식입니다.

- `추첨기`: 번호 범위, 뽑는 개수, 추첨 방식을 지정해 번호 추첨
- `번호 확인`: 저장된 추첨 기록 또는 복사해서 붙여넣은 여러 추첨 기록을 실제 당첨 번호와 비교

## 추첨 방식

### 기본

- 이미지 클릭 또는 `Space` 1회: 모든 릴 회전 시작
- 다시 클릭 또는 `Space`: 왼쪽 릴부터 오른쪽 릴까지 순차 감속/정지
- 마지막 릴은 추가 지연 후 정지

### 연속 자동

- 연속 실행 횟수를 `1~100회`로 지정
- 이미지 클릭 또는 `Space` 1회로 시작
- 기존 기본 추첨 동작을 지정 횟수만큼 자동 반복
- 각 회차 결과는 일반 추첨과 동일하게 추첨 기록에 자동 저장
- 실행 중 이미지 클릭 또는 `Space`를 다시 누르면 현재 회차를 마친 뒤 중지
- 화면 상태에 현재 회차와 전체 진행 횟수를 표시

### 하나씩 뽑기

- 첫 번째 이미지 클릭 또는 `Space`: 모든 릴 회전 시작
- 이후 입력 1회마다 왼쪽부터 릴 하나만 감속하여 정지하고 해당 번호를 공개
- 예를 들어 7개를 뽑는 경우 총 8회의 입력으로 완료
  - 1회: 7개 릴 전체 회전 시작
  - 2~8회: 1번부터 7번 릴까지 하나씩 수동 정지/공개
- 한 릴이 감속 중일 때 추가 입력은 무시해 중복 정지를 방지
- 마지막 릴이 정지하면 하나의 추첨 기록으로 저장

## 공통 추첨 설정

- 번호 범위 설정 가능
- 뽑는 개수 `1~7` 설정 가능
- 중복은 항상 비허용
- 추첨 방식, 번호 범위, 뽑는 개수, 연속 횟수는 `localStorage`에 저장
- Web Crypto API 기반 추첨
- 추첨 완료 시 최근 200회 자동 기록
- 현재 결과 / 개별 기록 / 전체 기록 복사 시 번호만 복사
- `전체 복사`는 한 줄에 한 조합씩 복사되어 번호 확인 탭에 그대로 붙여넣을 수 있음
- 날짜와 시간은 저장·표시·복사하지 않음

## 번호 확인

- 실제 당첨 번호를 공백 또는 쉼표로 입력
- 보너스 번호 사용 여부는 체크박스로 선택
- 보너스 번호 미사용 시 등수 대신 `N개 일치`만 표시
- 보너스 번호 사용 시 당첨 번호 6개 + 보너스 번호 입력을 기준으로 로또 방식 순위 판정
  - 6개 일치: 1등
  - 5개 + 보너스: 2등
  - 5개: 3등
  - 4개: 4등
  - 3개: 5등
  - 그 외: 낙첨
- 기존 자동 추첨 기록 전체와 일괄 비교
- `전체 복사`한 추첨 기록을 텍스트 영역에 그대로 붙여넣어 일괄 비교 가능
- 붙여넣기 형식은 한 줄에 한 조합, 각 번호는 공백·쉼표·세미콜론으로 구분 가능
- `현재 기록 넣기` 버튼으로 브라우저에 저장된 추첨 기록을 검사 입력창에 바로 불러올 수 있음
- 일치 번호를 결과 목록에서 강조 표시
- 최근 입력한 당첨 번호, 보너스 번호 사용 여부, 보너스 번호는 `localStorage`에 유지

## 이미지와 레이어

Base64나 별도 이미지 로더를 사용하지 않습니다.

```text
assets/Frame.png
```

릴 Canvas는 `Frame.png`보다 낮은 `z-index`에 배치되어 PNG의 입 구멍을 통해서만 보입니다. 페이지와 이미지가 축소·확대되어도 입 위치와 릴 크기는 비율로 함께 조정됩니다.

## 실행

별도 빌드 과정이 없습니다.

```bash
python -m http.server 8080
```

또는 GitHub Pages에서 `main` / `/ (root)`를 배포 대상으로 지정하면 바로 실행할 수 있습니다.
