게임 운영자 접속

실제 게임 운영자는 17832의 인증된 관리자 페이지를 사용합니다. 원격 링크에는 인증 토큰이 포함되므로 신뢰하는 운영자에게만 전달하세요.

관리자 인증 링크 재발급을 실행하면 현재 로그인된 모든 관리자 세션과 이전에 전달한 인증 링크가 즉시 무효화됩니다. 재발급 후에는 새 링크를 운영자에게 다시 전달해야 합니다.
