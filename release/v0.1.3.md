# RouletteBridge v0.1.3

첫 정식 Windows 배포 릴리스입니다.

## 주요 기능

- SOOP 스트리머 ID 기준 현재 방송 자동 조회
- 채팅 서버 연결 및 `SEND_BALLOON` 후원 이벤트 처리 기반
- 후원자별 별풍선 누적
- 기본값 `50개 = 티켓 1장`
- 1~28 중 중복 없는 7개 번호 자동 확정
- 번호 확정 후 OBS 방송용 룰렛 연출
- 룰렛 완료 후 티켓 PNG 자동 저장
- 후원자별 발급 번호 및 이미지 기록 유지
- SQLite 기반 누적/후원/티켓 영구 저장
- 프로그램 및 OBS 재시작 시 미완료 티켓 복구
- DB 백업, 수동 누적 보정, manifest 재생성 지원
- Java 설치 없이 실행 가능한 Windows x64 self-contained 패키지

## v0.1.3 수정 사항

- Windows EXE 콘솔 한글 인코딩 처리 개선
- 로그 파일에서는 정상적으로 보이던 JUL 레벨 `정보` 및 한글 로그 본문이 EXE 콘솔에서도 깨지지 않도록 UTF-8 콘솔 경로 적용
- `System.out` / `System.err` UTF-8 정렬
- 기존 UTF-8 로그 파일, config, manifest 저장 방식 유지
- 한글 인코딩 probe를 JAR과 패키지 EXE 양쪽에서 검증

## 검증

Windows CI에서 다음 항목을 통과한 배포본만 릴리스합니다.

- Maven build
- Phase D 후원 누적/자동 티켓 할당
- 중복 이벤트 차단
- Phase E PNG 저장 및 `ISSUED` 전환
- 동일 PNG 재업로드 멱등성
- Phase F 재시작 복구
- 기존 ticketId/번호 유지
- FAILED 자동복구 제외
- jpackage Windows EXE 생성
- 내장 Java runtime 확인
- 패키지 EXE 자체 Phase F self-test
- 패키지 EXE 한글 인코딩 probe

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.3.zip` 다운로드
2. 원하는 폴더에 압축 해제
3. `config.json`의 `streamerId`를 실제 방송 대상 ID로 변경
4. `RouletteBridge.exe` 실행
5. OBS Browser Source에 아래 주소 사용

```text
http://127.0.0.1:17820/soop-overlay.html?ws=ws://127.0.0.1:17821
```

## 업데이트 시 주의

기존 운영 중이라면 아래 항목은 삭제하거나 덮어쓰지 마세요.

```text
config.json
data/
tickets/
backups/
logs/
```

SQLite `data/roulette.db`가 누적 및 발급 기록의 원본입니다.

## 현재 실방송 검증 범위

테스트 스트리머 `20221010` 기준으로 방송 정보 조회, BNO 조회, 채팅 서버 연결, `JOIN_CHANNEL`까지 실제 검증했습니다.

실제 `SEND_BALLOON` 이벤트의 최종 실데이터 검증은 실제 후원 이벤트가 발생할 때 별도로 확인해야 합니다.
