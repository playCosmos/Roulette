룰렛/티켓 발급 기능과 분리된 보드게임 전용 서버입니다.

SOOP 수신 채널은 config.json의 streamerId를 사용합니다. 변경 후 프로그램을 다시 실행하세요.

보드게임 룸 생성

룸별 설정은 SQLite에 저장합니다. 생성 시 참가자별 SOOP 방송 상태를 확인하고, 서버가 만든 실제 보드 프리뷰를 확인한 뒤 배치를 확정합니다. DRAFT 룸은 여러 개 만들 수 있지만 동시에 활성화되는 룸은 최대 1개입니다.

룸 기본
참가자 / 후원 트리거

각 참가자의 SOOP ID와 정확히 일치하는 후원 이벤트만 사용합니다. 입력한 별풍선 수와 정확히 같은 단일 후원만 해당 참가자의 던지기 이벤트가 됩니다.

보드
이동값 생성

혼합은 매 턴 첫 던지기 직전에 주사위/윷 중 하나를 서버 RNG로 선택합니다. 같은 턴에서 더블·윷·모·지시문으로 추가 던지기가 이어져도 최초 선택한 종류를 턴 종료까지 유지합니다.

지시문 배치

왼쪽에서 지시문을 추가/선택하고 오른쪽 Property View에서 속성을 편집합니다. {n}, {m}처럼 중괄호로 표시한 값은 변경 가능한 인자입니다.

왼쪽 목록에서 지시문을 추가하거나 선택하세요.

자동 상속에서는 비율로 배치한 지시문만 랜덤 후보가 되며, 처음 지정한 비율이 그대로 가중치가 됩니다. 수량 배치 지시문은 기본 후보에서 제외됩니다.

설정을 입력한 뒤 룸을 생성하세요.
