# RouletteBridge v0.1.10

브리지 설정 변경 후 실제로는 `config.json` 저장이 성공했는데 관리자 페이지가 `저장 실패`로 표시하던 문제를 수정한 패치 릴리스입니다.

## 주요 수정

- 재시작이 필요한 브리지 설정을 저장할 때 `config.json` 저장 결과와 HTTP 응답이 브라우저에 충분히 전달된 뒤 프로세스가 종료되도록 자동 재시작 지연을 조정했습니다.
- 저장 성공 후 브리지 자동 재시작이 시작되는 정상 흐름에서 관리자 페이지가 네트워크 단절을 `저장 실패`로 오판하는 가능성을 줄였습니다.
- 기존 설정 저장 형식, 자동 재실행, 포트 변경 후 관리자 페이지 재연결 동작은 유지합니다.

## 포함 기능

- SOOP 후원 자동 티켓 발급 및 SQLite 영구 저장
- SOOP 수동 강제 재연결 및 반복 재연결 안정화
- 트레이 종료 graceful shutdown 및 프로세스 잔류 방지
- 관리자 설정 패널 자동 collapse
- 관리자 페이지/OBS 오버레이 자동 재연결
- 현재 채널 실시간 분석 페이지
- 채팅, 별풍선, 입장/퇴장, 구독, 팬레터, 미션, 관리/제재, reconnect/disconnect, RAW/unknown 등 전체 `ChatEvent` 관찰
- 채널 분석 이벤트 검색, 필터, 일시정지, 자동 스크롤, parsed payload/raw packet 확인

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.10.zip`을 다운로드해 압축을 해제합니다.
2. 기존 운영 데이터를 유지하려면 기존 `config.json`, `data/`, `tickets/`, `backups/`를 보존합니다.
3. `RouletteBridge.exe`를 실행합니다.
4. 관리자 페이지에서 설정을 변경하고 저장합니다.
5. 재시작이 필요한 변경이라면 저장 성공 안내 후 브리지가 자동 재실행되고 관리자 페이지가 다시 연결됩니다.
