# RouletteBridge v0.1.7

Windows용 SOOP 자동 티켓 발급 브리지 안정화 배포판입니다.

## 주요 변경 사항

- 관리자 페이지에서 SOOP 연결 완료 후 `브리지 설정` 패널을 자동으로 접도록 개선
- 연결 전/설정 필요 상태에서는 설정 패널을 펼쳐 유지
- 연결 후 사용자가 직접 설정 패널을 펼친 경우 상태 갱신으로 다시 강제 접히지 않도록 처리
- `SOOP 재연결` 동작을 기존 클라이언트를 폐기하는 방식에서 라이브러리의 강제 재연결 경로로 변경
- 재연결 과정에서 발생하는 정상적인 disconnect 이벤트를 장애로 오인하지 않도록 상태 관리 보강
- 각 연결/재연결 시도에 attempt 추적을 적용해 이전 timeout이 새 시도를 종료하지 않도록 수정
- 재연결 실패 이후에도 다음 수동 재연결을 다시 시도할 수 있도록 개선
- 트레이 `종료`에서 AWT 이벤트 스레드가 직접 `System.exit()`를 호출하던 구조 제거
- 별도 종료 스레드에서 Tray, HTTP, Overlay WebSocket, SOOP, 로그를 순차 종료하도록 변경
- 중복 종료 요청을 한 번만 처리하는 idempotent shutdown 적용
- 종료 과정이 비정상적으로 지연될 경우 프로세스가 작업 관리자에 계속 남지 않도록 bounded shutdown 안전장치 추가

## 포함 기능

- Windows System Tray 백그라운드 실행
- 관리자 페이지에서 `config.json` 편집 및 저장
- 최초 설정이 필요하면 관리자 페이지 자동 열기
- 재시작이 필요한 설정은 `restart-bridge.ps1`을 이용해 자동 재실행
- 관리자 페이지의 브리지 재연결 대기 및 복구 표시
- OBS 오버레이의 무표시 자동 재연결
- 관리자 페이지에서 OBS 오버레이 주소 확인 및 복사
- 수동 누적 보정 시 기존 후원자 자동 확인 및 신규 사용자 별도 SOOP 직접 조회
- 후원 누적, 티켓 할당, PNG 저장, SQLite 복구 기능

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.7.zip`을 다운로드해 원하는 폴더에 압축을 해제합니다.
2. 기존 운영 데이터가 있다면 `config.json`, `data/`, `tickets/`, `backups/`를 유지합니다.
3. `RouletteBridge.exe`를 실행합니다.
4. 트레이 아이콘에서 관리자 페이지를 열어 상태와 설정을 확인합니다.
5. OBS Browser Source 주소는 관리자 페이지의 `OBS 오버레이 주소`에서 복사합니다.

## 검증

Windows CI에서 다음 검증을 통과한 패키지만 릴리스합니다.

- Admin/Overlay JavaScript 문법 검사
- Java 25 Maven build
- Phase D 후원 누적 및 자동 티켓 할당 self-test
- Phase E PNG 저장 및 발급 상태 전환 self-test
- Phase F 재시작 복구 self-test
- Windows `jpackage` GUI/Tray app-image 생성
- 내장 Java runtime 확인
- 배포 설정 구조 확인
- `restart-bridge.ps1` 및 관리자/오버레이 자산 포함 확인
- 배포본에 로그 폴더가 사전 생성되지 않는지 확인
- 패키지된 EXE 자체 Phase F/encoding self-test

트레이 메뉴를 실제 마우스로 눌러 종료하는 동작은 CI가 GUI 상호작용까지 수행하지 않으므로, 배포 후 실제 Windows 환경에서 `종료` 시 프로세스가 완전히 사라지는지 확인하는 것이 권장됩니다.
