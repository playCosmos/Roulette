# RouletteBridge v0.1.13

관리자 페이지에서 발급 완료된 티켓 번호를 이미지 없이 조회하고, 추첨 페이지 참가자 입력에 바로 붙여넣을 수 있도록 복사 기능을 추가한 릴리스입니다.

## 주요 변경 사항

- 관리자 페이지에 `발급 티켓 조회` 패널 추가
- 발급 완료된 티켓을 후원자별로 그룹화하여 표시
- 각 후원자 그룹을 개별적으로 `접기 / 펼치기` 가능
- 새로고침이나 검색으로 그룹이 다시 그려져도 현재 페이지에서 후원자별 접힘 상태 유지
- 닉네임 또는 SOOP ID로 발급 티켓 검색 지원
- 각 티켓의 티켓 순번, 번호 조합, 발급 시각 표시
- 각 티켓별 `복사` 버튼 추가
- 각 후원자별 `전체복사` 버튼 추가
- 전체복사는 한 줄에 한 조합 형식으로 복사하여 `index.html` 추첨 페이지의 후원자 `보유 번호` 입력란에 그대로 붙여넣을 수 있도록 구성
- 복사되는 번호는 오름차순으로 정렬
- 발급 번호 조회는 이미지 파일을 읽지 않고 SQLite DB의 `ticket.numbers_json`을 직접 사용
- 관리자 전용 `GET /api/admin/tickets` 조회 API 추가
- 기존 `index.html` 및 추첨 페이지 동작은 변경하지 않음

## 복사 형식

후원자 전체복사 예시:

```text
1 4 7 12 16 22 28
2 5 9 13 18 21 27
3 6 10 14 19 23 25
```

각 줄이 하나의 티켓 조합이며, 추첨 페이지의 해당 후원자 `보유 번호` 입력란에 그대로 붙여넣을 수 있습니다.

## 다운로드

- `RouletteBridge-Windows-x64-v0.1.13.zip`: 전체 Windows x64 패키지
- `RouletteBridge-Patch-v0.1.12-to-v0.1.13.zip`: 기존 v0.1.12 설치용 패치

### 패치 ZIP 사용 방법

1. 실행 중인 RouletteBridge를 트레이 메뉴에서 완전히 종료합니다.
2. 기존 설치 폴더를 백업합니다.
3. 패치 ZIP의 내용을 기존 RouletteBridge v0.1.12 설치 폴더에 그대로 덮어씁니다.
4. `RouletteBridge.exe`를 다시 실행합니다.

패치 ZIP에는 `config.json`, `data/`, `tickets/`, `backups/`, `runtime/`가 포함되지 않아 기존 설정과 운영 데이터를 덮어쓰지 않습니다.

## 검증

Windows Release CI에서 다음 항목을 통과한 패키지만 게시합니다.

- Admin / Channel Analyzer / Overlay JavaScript 문법 검사
- Java 25 Maven build
- Phase D 발급 테스트
- Phase E PNG 저장 테스트
- Phase F 복구 및 운영 테스트
- encoding probe
- Windows GUI/Tray app-image 생성
- 패키지된 EXE Phase F/encoding probe
- 내장 Java runtime 확인
- 배포 기본값 `issuanceMode = single_donation` 확인
- 관리자 페이지의 발급 티켓 조회 UI 포함 확인
- 후원자별 접기/펼치기 제어 포함 확인
- 관리자/오버레이/채널 분석 자산 포함 확인
- 배포용 `streamerId` 공란 확인
- 배포본에 로그 폴더가 사전 생성되지 않는지 확인
