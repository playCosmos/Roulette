# RouletteBridge v0.1.5

Windows용 SOOP 자동 티켓 발급 브리지 배포판입니다.

## 주요 변경 사항

- `RouletteBridge.exe`를 콘솔 창 없이 Windows 시스템 트레이에서 실행
- 트레이 메뉴에서 SOOP 상태 확인, 관리자 페이지 열기, OBS 오버레이 열기, SOOP 재연결, 종료 지원
- 트레이 아이콘 더블클릭으로 관리자 페이지 열기
- 관리자 페이지의 연결 상태 자동 갱신
- 후원자가 없을 때 `등록된 후원자가 없습니다.`로 빈 상태 표시
- DB 백업, `issued.json` 재생성, 수동 누적 보정의 성공/실패 결과 표시
- 테스트 티켓은 OBS/오버레이 연결 상태에 따라 자동 활성/비활성
- 오버레이 미연결 상태에서 테스트 티켓 요청 시 명확한 오류 표시
- 관리자 JavaScript/CSS가 Windows 배포본에 반드시 포함되도록 패키징 및 CI 검증 강화
- 내부 로그 폴더를 Windows에서 숨김 처리하고 트레이/관리 UI에서는 노출하지 않음
- Java 설치 없이 실행 가능한 Windows x64 self-contained 패키지 유지

## 사용 방법

1. `RouletteBridge-Windows-x64-v0.1.5.zip`을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. `config.json`의 `streamerId`에 실제 방송 대상 ID를 입력합니다.
4. `RouletteBridge.exe`를 실행합니다.
5. 프로그램은 Windows 알림 영역의 트레이 아이콘으로 동작합니다.
6. 트레이 아이콘을 더블클릭하면 관리자 페이지를 열 수 있습니다.
7. OBS Browser Source에는 아래 주소를 사용합니다.

```text
http://127.0.0.1:17820/soop-overlay.html?ws=ws://127.0.0.1:17821
```

## 관리자 페이지

```text
http://127.0.0.1:17820/soop-admin.html
```

관리 페이지에서는 SOOP 상태, 스트리머 ID, 미완료 티켓 수, Overlay 연결 수, 후원자 누적을 확인할 수 있습니다.

운영 도구:

- DB 백업
- `issued.json` 재생성
- 테스트 티켓
- 수동 별풍선 누적 보정

테스트 티켓은 Overlay 연결 수가 1 이상일 때 사용할 수 있습니다.

## 업데이트 시 주의

기존 운영 중이라면 아래 항목은 삭제하거나 덮어쓰지 마세요.

```text
config.json
data/
tickets/
backups/
```

SQLite `data/roulette.db`가 누적 및 발급 기록의 원본입니다.

## 검증

Windows CI에서 다음 항목을 통과한 배포본만 릴리스합니다.

- Admin JavaScript 문법 검사
- Maven build
- Phase D 후원 누적/자동 티켓 할당
- 중복 이벤트 차단
- Phase E PNG 저장 및 `ISSUED` 전환
- 동일 PNG 재업로드 멱등성
- Phase F 재시작 복구
- 기존 ticketId/번호 유지
- `FAILED` 자동복구 제외
- jpackage Windows GUI/Tray EXE 생성
- 내장 Java runtime 확인
- 관리자 JS/CSS 패키지 포함 확인
- 배포 config 구조 확인
- 배포본에 로그 폴더가 사전 생성되지 않는지 확인
- 패키지 EXE 자체 Phase F/encoding self-test
