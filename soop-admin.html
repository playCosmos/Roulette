보드게임 룸 생성

룸별 설정은 SQLite에 저장합니다. 생성 시 참가자별 SOOP 방송 상태를 확인하고, 서버가 만든 실제 보드 프리뷰를 확인한 뒤 배치를 확정합니다. DRAFT 룸은 여러 개 만들 수 있지만 동시에 활성화되는 룸은 최대 1개입니다.

룸 기본
참가자 / 후원 트리거

각 참가자의 SOOP ID와 정확히 일치하는 후원 이벤트만 사용합니다. 입력한 별풍선 수와 정확히 같은 단일 후원만 해당 참가자의 던지기 이벤트가 됩니다.

보드
이동값 생성

이동 중 경유 칸은 실행하지 않고 최종 도착 칸 지시문만 처리합니다. 도착 지시문 처리가 끝난 뒤 보너스 던지기를 진행하며, 다음 던지기 스킵은 아직 실행하지 않은 보너스 던지기도 취소합니다.

지시문 배치

기본 아무 효과 없음 칸은 별도 배치하지 않은 나머지 칸입니다. 아래 기본 칸과 랜덤칸을 필요한 만큼 추가하세요.

자동 상속에서는 비율로 배치한 지시문만 랜덤 후보가 되며, 처음 지정한 비율이 그대로 가중치가 됩니다. 수량 배치 지시문은 기본 후보에서 제외됩니다.

설정을 입력한 뒤 룸을 생성하세요.

OBS 오버레이 주소

OBS의 브라우저 소스 URL에 아래 주소를 그대로 입력합니다. 브리지 재시작 중에도 열려 있는 오버레이는 자동 재연결합니다.

Overlay 값이 1 이상이면 방송용 오버레이가 브리지에 연결된 상태입니다.
